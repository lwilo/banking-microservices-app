# Banking Microservices Application 🏦

## 📋 Description
Application bancaire basée sur une architecture micro-services avec Spring Boot et Spring Cloud.

## 🗂️ Structure du projet
```
banking-microservices-app/
├── partie1/              # Tutoriel guidé
│   ├── customer-service/
│   ├── inventory-service/
│   ├── gateway-service/
│   ├── eureka-server/
│   ├── billing-service/
│   └── config-service/
│
└── partie2/              # Projet bancaire
    ├── beneficiaire-service/
    ├── virement-service/
    ├── chat-bot-service/
    ├── gateway-service/
    ├── discovery-service/
    └── config-service/
```

## 🛠️ Technologies
- Spring Boot 3.2.x
- Spring Cloud
- Java 17
- Maven
- H2 Database / PostgreSQL
- Angular/React
- Docker

## 📦 Micro-services

### Partie 1 - Tutoriel
1. **customer-service** - Gestion des clients
2. **inventory-service** - Gestion des produits
3. **gateway-service** - API Gateway
4. **eureka-server** - Service Discovery
5. **billing-service** - Service de facturation
6. **config-service** - Configuration centralisée

### Partie 2 - Application Bancaire
1. **beneficiaire-service** - Gestion des bénéficiaires
2. **virement-service** - Gestion des virements
3. **chat-bot-service** - Chatbot IA avec RAG
4. **gateway-service** - API Gateway
5. **discovery-service** - Service Discovery
6. **config-service** - Configuration centralisée

## 🚀 Démarrage

### Prérequis
- Java 17+
- Maven 3.6+
- Git

### Installation
```bash
git clone https://github.com/lwilo/banking-microservices-app.git
cd banking-microservices-app
```
